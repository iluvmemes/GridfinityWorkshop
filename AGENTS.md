# User preferences

- Always include press-fit magnet holes on Gridfinity items made for the project owner, unless explicitly requested otherwise.
- Use the existing project press-fit preset (6.08 mm hole diameter, 2.4 mm depth, four standard magnet positions per 42 mm cell) unless a different magnet size or fit is specified.
- Use 21 mm body tops for shallow-drawer bins and 35 mm body tops for deeper-drawer bins. Heights are measured from the bottom of the bin feet; raised lettering/logo is additional. Preserve pocket depths when changing body height. Cart drawers B/C are shallow; A/D/E/F are deeper.

# Commit privacy requirements

- Never commit the project owner's email address or identifying information, including their name, usernames, account identifiers, personal paths, machine names, contact details, or other information that could identify them. Use neutral placeholders in examples and documentation.
- Never include AI agent names, model names or versions, provider/company identities, agent attribution, or other identifiable agentic information in committed content, commit messages, author/committer metadata, trailers, generated artifacts, or filenames. Do not add agent co-author or attribution trailers. Required generic policy wording in coding instructions is permitted.
- Use the repository-local neutral Git identity: `Project Contributor <contributor@example.invalid>`. Do not fall back to a personal global identity.
- Before committing, inspect the staged diff, staged filenames, proposed message/trailers, and effective author and committer identities for these disclosures. Remove or anonymize any violations before committing. Apply these rules to every coding workflow and generated output in this repository.
